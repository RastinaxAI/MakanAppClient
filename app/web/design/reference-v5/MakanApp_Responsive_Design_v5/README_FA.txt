ماکان — طراحی جزئی پاسخ‌گو، نسخه ۵ آبی
تاریخ تحویل: ۱۵ آبان ۱۴۰۵ / ۶ نوامبر ۲۰۲۶

569 صفحه PDF، 528 موقعیت طراحی، 1584 قاب اصلی متناسب موبایل، تبلت و دسکتاپ.
همه ۴۶۷ شناسه نسخه قبلی حفظ و در سه دستگاه بازچینی شده‌اند؛ ۶۱ موقعیت برای ریزرفتارها افزوده شده است.
این شمارش، سه طراحی دستگاه برای یک موقعیت را نشان می‌دهد؛ به معنی ۱۵۸۴ قابلیت محصول نیست.

فایل‌ها
PDF کامل با فهرست داخلی پیونددار و نشانک فصل‌ها، در اندازه A2 افقی، با متن و اجزای برداری قابل زوم.
MakanApp_Responsive_Design_FA_v5.html: مرورگر محلی طراحی؛ فونت، اجزا و داده همه موقعیت‌ها در فایل جاسازی شده‌اند.
responsive_inventory.json و CSV: شناسه، نقش، وضعیت محصول، صفحه نسخه ۵، مرجع نسخه ۴ و فیلدهای هر موقعیت.
api_candidate_mapping_v5.csv: نگاشت خانواده‌های ۴۴۲ عملیات به قاب‌های نامزد در نسخه ۵؛ اتصال دقیق هر کنترل یا اجرای عملیاتی را ادعا نمی‌کند.
api-reference: قرارداد ثبت‌شده ۵ نوامبر ۲۰۲۶ با ۳۹۱ مسیر، ۴۴۲ عملیات و ۷۲۰ طرح‌واره؛ در این مرحله قرارداد دوباره دریافت یا عملیات اجرا نشده است.
verification: نتیجه بررسی چیدمان، عرض‌های مختلف، کنتراست و مرورگر طراحی؛ آزمون محصول واقعی نیست.
editable-source: منبع و اجزای ساخت سند و مرورگر، CSS پاسخ‌گو، حالت‌ها و داده‌های طراحی.

مرور HTML
۱. فایل HTML را در مرورگر باز کنید. به اینترنت و ورود به حساب نیاز ندارد.
۲. با عنوان یا شناسه جستجو کنید؛ برای رفتن مستقیم، MK-95 یا RX-001 بنویسید.
۳. «مقایسه سه نما» یک موقعیت را کنار هم نشان می‌دهد. برای خواندن ریزه‌کاری‌ها، «یک نما با اندازه دلخواه» را انتخاب کنید.
۴. اندازه‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۳۰، ۷۶۸، ۸۳۴، ۱۰۲۴، ۱۱۹۴، ۱۲۸۰، ۱۴۴۰ و ۱۹۲۰ آماده‌اند. عرض و ارتفاع دلخواه هم قابل انتخاب‌اند.
۵. تم روشن/تاریک و متن ۲۰۰٪ برای بررسی بازچینی در دسترس‌اند. در متن بزرگ، پنج مقصد موبایل در دو ردیف ۳+۲ قرار می‌گیرند تا نام‌ها کامل بمانند.
۶. ورودی‌های نمونه قابل ویرایش‌اند؛ متن هنگام تغییر تم و اندازه حفظ می‌شود. هیچ داده یا فرمانی به API ارسال نمی‌شود.
۷. PDF خط دید مرجع هر قاب را نشان می‌دهد. در نماهای بلند، نشانه پیمایش آمده و ادامه محتوا در HTML قابل دیدن است.
۸. لینک دریافت PDF زمانی کار می‌کند که HTML اصلی و PDF در همان پوشه باشند.

دامنه و وضعیت تصمیم‌ها
پنج مقصد اصلی ثابت‌اند. کلاس مستقل، آموزشگاه نیست و عضویت یا گزارش والد سازمانی، مجوز خودکار کلاس مستقل نمی‌سازد.
درخواست تشکیل برای همه حساب‌های فعال است؛ درخواست‌دهنده مدیر پیش‌فرض و تعیین نهایی مدیر با مالک/ادمین است.
مدرس اختیاری است. حساب عادی و Student می‌توانند عضو آموزشی محلی باشند. دعوت و درخواست پیوستن دو ورودی برای یک عضویت نهایی‌اند.
یک گروه و یک کانال به کلاس متصل‌اند؛ ساخت، ترمیم و همگام‌سازی دسترسی باید در اتصال واقعی آزموده شوند.
تکلیف و آزمون مستقل با وجود قرارداد همچنان نیازمند تأیید نهایی عرضه محصول‌اند. product_pending در فهرست آن‌ها را مشخص می‌کند.
جزئیات تازه RX پیشنهاد رفتار رابط‌اند؛ داده‌ها، قیمت‌ها، افراد، فایل‌ها و نتیجه‌ها نمونه‌اند و وضعیت واقعی مشتری نیستند.
جلسه و درس مستقل، کشف عمومی، قواعد بازگشایی بایگانی، تغییر شماره، حذف حساب و تیکت تعاملی تصمیم یا قرارداد تکمیلی می‌خواهند.

ادامه ویرایش
برای ساخت خروجی از منبع، Node.js و npm لازم‌اند. در editable-source دستور npm install و سپس npm run build را اجرا کنید.
داده آماده در assets/scenes.json است. layout.cjs قواعد بازچینی و responsive.css جزئیات سه دستگاه را تعریف می‌کنند.
برای بازسازی داده اولیه پس از تغییر source_scenes.json یا new-scenes.cjs، ابتدا npm run prepare:scenes و سپس npm run build را اجرا کنید.
بازسازی داده از Playwright استفاده می‌کند؛ مرورگر Chromium یا مسیر مرورگر در MAKAN_CHROME لازم است.
build فایل HTML و پوشه print با صفحات آماده چاپ A2 تولید می‌کند. PDF تحویلی از همین صفحات ساخته و با بررسی تصویری و پیوندهای داخلی تکمیل شده است.
این منبع، کد محصول منتشرشده یا اتصال کامل برنامه به بک‌اند نیست.

پذیرش اجرای واقعی
مجوز مؤثر، ظرفیت و گذار وضعیت از نتیجه معتبر خوانده شوند؛ نمایش دکمه جای بررسی مجوز نیست.
رفتار تکرار فرمان، نتیجه مبهم، انقضا، فایل خصوصی و دسترسی پس از لغو عضویت آزموده شوند.
مقادیر role/capability رشته‌ای، محدودیت‌ها، خطاها، زمان و قواعد انتشار با قرارداد نهایی نگاشت شوند.
صفحه‌خوان، کنترل بومی، بزرگ‌نمایی مرورگر، جهت تبلت، کارایی و امنیت روی محصول نهایی بررسی شوند.
