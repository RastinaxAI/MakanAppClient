# مالکیت استایل و حدود نمونهٔ اولیه

برنامهٔ فعال Next.js داخل `web/` است. CSS Modules جای import عمومیِ دو stylesheet اطلس را گرفته‌اند؛ HTML اطلس یا PDF در route محصول mount نمی‌شود. مهاجرت پیشینِ این کار از ابتدا دوباره اجرا نشده است.

| مسئلهٔ ثبت‌شده | مالک و راه‌حل فعلی | شاهد و حد نتیجه |
| --- | --- | --- |
| headingهای عمومی و بازتعریف‌های بعدی | `app/globals.css` برای reset/type عمومی؛ هندسهٔ Auth و shell در `components/v5/frame.module.css` و `scene.module.css` | مستطیل متن عنوان، ورودی و اقدام در سه اندازه؛ این نتیجه به تمام عنوان‌های بلند تعمیم ندارد. |
| فونت و تم چندمالک | یک Vazirmatn معتبر در globals، aliasهای تم در `design/tokens.css` و مولد محدودِ token؛ انتخاب کاربر حفظ است | فونت در۸۴قاب آماده است؛ اطلاعات computed و winner برای۳۶عنصر ورود ثبت شده‌اند. |
| Button/Input با utility و cascade قدیمی | variant مشترک Button و ورودی‌های native؛ کنترل‌ها در CSS Modules صاحب اندازه/مرز هستند | ورودی/کد ورود، اقدام جمع‌وجور دسکتاپ، هدف لمس و متن۲۰۰٪ در تست‌های فعلی پوشش دارند. |
| CSS اطلس و selector حالت روی DOM متفاوت | قواعد لازم به ماژول اجزا و صحنه منتقل شده‌اند؛ state مؤثر روی DOM واقعی اندازه‌گیری می‌شود | Direct chat و سایر صفحات اصلی اندازه‌گیری شدند؛ وجود selector با نام قدیمی به‌تنهایی شاهد مصرف یا علت خطا نیست. |
| بازتعریف‌های messenger | اعلان‌های متعارض/تکراری در شرط یکسان ادغام شدند؛ breakpointهای متفاوت حفظ‌اند | تم روشن/تاریک، فیلتر، کنتراست، draft و سه‌پنل آزموده شدند. |
| reset وابسته به Tailwind | reset لازم مستقل و utilityهای مؤثر به CSS معمولی منتقل شدند؛ import/plugin و سه وابستگی مستقیم با lockfile حذف شدند | build/production عبور کردند. Tailwind علت همهٔ اختلاف‌ها معرفی نمی‌شود. |
| پنجره در متن بزرگ | سطح اسکرولِ large reading در ماژول Dialog بازگردانده شد | تست عنوان بلند، Escape، focus loop/return و اقدام قابل دسترس موفق است. |
| گزینه‌های radio بدون استایل مشترک | فهرست انتخاب از ماژول صفحهٔ ظاهر به primitive مشترک منتقل شد | حضور و غیاب، حریم خصوصی و کنترل‌های متن بزرگ در مجموعهٔ فعلی موفق‌اند. |

نام‌های معنایی قدیمی در کلاس‌ها hook فنیِ بدون stylesheet سراسری‌اند؛ helper `components/v5/classes.ts` hash محلیِ primitive واقعی را اضافه می‌کند. فایل‌های فعال با نام `v4` معادل اپ Vite بازنشسته نیستند. route، context و قرارداد API با نام فایل CSS حذف یا بازسازی نشده‌اند.

رسید cascade: `docs/quality/CSS_CASCADE_PROTOTYPE_20261110.json` شامل DOM، computed property، selectorهای matched، specificity و ترتیب و نامزدهای فایل/خط است. property ارث‌رسیده یا shorthand ممکن است بیش از یک نامزد داشته باشد؛ گزارش این ابهام را نگه می‌دارد و اسکن ایستا را تشخیص قطعی تمام اختلاف‌ها نمی‌داند.

هندسهٔ جاری در `docs/design/exact-v1/prototype-eighth-geometry.json` ثبت است.۱۲اندازه‌گیری Parent هنوز جفت‌شدن برنامهٔ خالیِ دادهٔ فعلی با برنامهٔ پُر مرجع را دارند؛۱۰استثنای ارتفاع پنل زمینه نیز متن/ردیف متفاوت دارند. این‌ها برابری پیکسلی نیستند و با padding خالی، ردیف جعلی یا پنهان‌کردن overflow پوشانده نشده‌اند. تصاویر جدید، build واقعی خودشان را دارند.

پاک‌سازی فقط پس از بررسی مصرف و آرشیوِ قابل بازیابی انجام شد: چهار فایل جایگزین‌شده،۱۰۰٬۰۱۸بایت. مرجع V5، قرارداد، تست، ابزار معتبر، اسرار، نشست، volume، build فعال و فایل‌های نامشخص حفظ‌اند. [manifest و راه بازیابی](../quality/CSS_STATIC_CLEANUP_20261110.json) و [رسید نمونهٔ اولیه](../quality/PROTOTYPE_E5BD3EA_20261110.json) مرز پوشش را جدا از رفتار/API نشان می‌دهند.
