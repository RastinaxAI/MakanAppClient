سطح قبلی کلاینت فقط GET پیکربندی داشت؛ snapshot کامل، عملیات ثبت، فهرست و حذف را نیز داشت. سه عملیات self به SDK موجود افزوده و به همان برنامه متصل شدند. اجازهٔ مرورگر، ترجیح حساب و ثبت تأییدشدهٔ سرویس جدا هستند. هیچ درخواست مجوز یا POST ثبت روی mount انجام نمی‌شود. ثبت تنها پس از پاسخ۲۰۰ معتبر و تطبیق شناسه/زمان ایجاد با ثبت فعال خود حساب تأیید می‌شود؛ رد مجوز، پاسخ نامرتبط،۲۰۲ یا پاسخ گم‌شده موفقیت نیست.

استفادهٔ اشتباه از V4Note، متن ساده را به کادر تبدیل کرده بود؛ markup مطابق مرجع اصلاح شد. خلاصهٔ داخل portal از اجزای مشترکِ پنجره استفاده می‌کند. variant موجود، حذف را در موبایل bottom sheet، تبلت dialog و دسکتاپ drawer می‌سازد؛ لایهٔ CSS وصله‌ای اضافه نشد. بازخوانی و reload ارتباط ثبت نامطمئن را دور نمی‌زنند. حذف فقط۲۰۴ را می‌پذیرد؛ بعد از بسته‌شدن پنجره نیز فهرست دوباره خوانده می‌شود و حذف تکرار خودکار ندارد. دستگاه دیگر حساب، نشست ورود و ترجیح حساب حفظ می‌شوند.

تغییر فقط push، مقادیر ساعات سکوتِ غیرفعالِ بازگردانده‌شده را پاک نمی‌کند. شکل‌های مجاز شمارهٔ نسخه در قرارداد پذیرفته می‌شوند. فضای آموزشگاه فعال می‌ماند، اما زمینهٔ این بخش صریحاً شخصی است. نام «مرورگر فعلی» از اولین ردیف Web حدس زده نمی‌شود. متن نمونهٔ «گوشی اندروید» در clone مقایسه به برچسب عمومیِ همان platform تبدیل شده است؛ DTO نام دستگاه یا شکل گوشی ندارد. فایل‌های اصلی مرجع تغییر نکرده‌اند و لوگوی تأییدشدهٔ محصول حفظ شده است.
