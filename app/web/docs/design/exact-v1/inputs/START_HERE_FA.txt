بستهٔ اجرای دقیق طراحی ماکان — راهنمای شروع
۷ نوامبر ۲۰۲۶

این بسته برای اصلاح رابطِ پروژهٔ واقعیِ فرانت‌اند بر پایهٔ طرح نسخهٔ ۵ است.
فایل PDF و منابع طراحی نسخهٔ قبلی تغییر نکرده‌اند. یک پرامپت اجرایی، مشاهده‌های محدود سایت و جدول نگاشت اولیه به آن‌ها افزوده شده است.

۱. پروژهٔ واقعی فرانت‌اند را در Codex باز کنید. بستهٔ طراحی به‌تنهایی سورس برنامه نیست.
۲. این ZIP را ضمیمه کنید یا آن را در مسیر docs/design/makan-v5 داخل همان پروژه باز کنید.
۳. متن IMPLEMENTATION_PROMPT_FA.txt را به Codex بدهید. اگر فایل‌ها داخل پروژه قرار گرفته‌اند، می‌توانید متن زیر را ارسال کنید:

«فایل IMPLEMENTATION_PROMPT_FA.txt در بستهٔ MakanApp_Exact_UI_Implementation_Pack_v1 را کامل بخوان و روی همین ریپوی واقعی فرانت‌اند اجرا کن. هدف، تطبیق طراحی نسخهٔ ۵ در همهٔ بخش‌ها و هر سه دستگاه است. PDF، HTML، توکن‌ها، inventory و CSS مرجع در پوشهٔ reference قرار دارند. ابتدا نگاشت طراحی به route/component و اختلاف‌های واقعی را تهیه کن، سپس اجزای مشترک و صفحه‌ها را اصلاح کن و با screenshot هم‌اندازه بررسی کن. فقط تغییر رنگ یا اجرای generator اطلس کافی نیست. همهٔ کارهای قابل انجام را تا تحویل preview و گزارش پوشش ادامه بده.»

فایل‌های افزوده‌شده
IMPLEMENTATION_PROMPT_FA.txt — دستور کامل و قابل کپی برای پیاده‌ساز.
LIVE_REVIEW_2026-11-07.json — مشاهدات واقعیِ صفحهٔ ورود عمومی و محدودیت بررسی؛ بخش‌های پس از ورود بررسی نشده‌اند.
screen-route-matrix.csv — ۵۲۸ ردیف طراحی؛ route و component واقعی هنوز باید در ریپوی برنامه شناسایی شوند. این جدول گزارش تکمیل پیاده‌سازی نیست.
reference-previews — چند تصویر از صفحات PDF برای مرور سریع.
reference — بستهٔ اصلی نسخهٔ ۵، شامل PDF، HTML محلی، CSS و منبع تولید اطلس، توکن‌ها، inventory و snapshot سند API.

موارد مهم
برای تطبیق بصری، قاب داخلی همان دستگاه و همان شناسه را معیار بگیرید؛ حاشیهٔ سند A2 و بدنهٔ گوشی بخشی از محصول نیستند.
در design-tokens.json فیلد responsiveV5 اندازه‌های به‌روز را دارد.
مدل نباید فایل HTML اطلس را به‌جای برنامه deploy کند یا همهٔ ۵۲۸ موقعیت را ۵۲۸ route مستقل فرض کند.
تم تاریکِ مشاهده‌شدهٔ سایت با مقادیر تم تاریک مرجع نزدیک است. برای مقایسه باید theme و حالت focus یکسان باشند.
در بررسی عمومی سایت به /enter هدایت شدیم؛ بررسی API عملیاتی، حساب‌های داخلی، عملکرد پس از ورود و کد ریپوی برنامه در این بسته ادعا نشده است.
تکلیف و آزمون فوق‌برنامه همچنان از نظر عرضه نیازمند تأیید نهایی محصول‌اند.
