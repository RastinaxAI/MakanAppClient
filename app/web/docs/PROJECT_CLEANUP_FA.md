# پاک‌سازی و سبک‌سازی پروژه — ۶ نوامبر ۲۰۲۶

پیش‌نمایش‌های توسعه از برنامه حذف شدند: مسیرهای `/preview/reference/*` اکنون ۴۰۴ هستند. ۴۸۲ فایل دادهٔ تولیدیِ نمایش مرجع، ۴۲۹ فایل binding بدون مصرف، قالب‌ها و CSSهای بلااستفاده، بارگذارهای قدیمی و ابزارهای منسوخِ مرور نما حذف شدند. PDF و منابع اصلی طراحی، bindingهای مصرف‌شدهٔ صفحات واقعی و گالری ایستای آخرین بررسی V5 حفظ شدند.

کش‌های قدیمی Next، ساخت‌های آزمایشیِ کپی‌شده، گزارش‌های موقت مرورگر، تصاویر مراحل قبلی و بستهٔ تصویری قدیمی V4 پاک شدند. دادهٔ واقعیِ نشست‌ها، فایل‌های خصوصی و volumeهای Docker محفوظ‌اند. فایل‌های ریشه که نقشِ مستقلی دارند، از جمله ورودی‌های مرجع کاربر، به‌طور حدسی حذف نشدند. تست‌ها و ابزار ساخت برای ادامهٔ نگه‌داری لازم‌اند و باقی ماندند.

حجم `web` بدون `node_modules` و `.git`، از **3.33 GB** پیش از پاک‌سازی خروجی‌ها به حدود **0.45 GB** با build قابل اجرا رسید؛ تقریباً **2.88 GB** کمتر. اندازه‌گیری اول پس از حذف اولیهٔ کد پیش‌نمایش انجام شد. حجم `src` از حدود ۴۵ به ۶ مگابایت و تعداد ماژول‌های بررسی‌شدهٔ lint از ۷۶۶ به ۳۲۵ رسید.

## بهبود بارگذاری

پنجرهٔ راهنمای ورود هنگام درخواست کاربر بارگیری می‌شود و پس از بستن، فوکوس به دکمهٔ بازکننده برمی‌گردد. تابع تنظیم خوانایی از صفحهٔ تنظیمات جدا شد تا راه‌اندازی تم، وابستگی صفحه را وارد نکند. وابستگی استفاده‌نشدهٔ `@hookform/resolvers` از package و lockfile حذف شد.

در یک اجرای کنترل‌شدهٔ محلی، JavaScript اولیهٔ ورود از **753,560** به **705,412 بایت** رسید: **6.39٪ کاهش** و ۱۴ به ۱۲ درخواست. این اندازهٔ بازشدهٔ اسکریپت است، نه اندازهٔ فشردهٔ شبکه. FCP در همین نمونه ۲۷۲ به ۱۷۶ میلی‌ثانیه بود؛ به دلیل اثر بار میزبان، افزایش سرعت عمومی یا سرعت سرور اصلی از آن نتیجه‌گیری نشده است. اندازهٔ اسکریپت آموزشگاه با جابه‌جایی chunkها کمی بیشتر شد و در رسید پنهان نشده است.

## بررسی انجام‌شده

ساخت production، ۵۰۰ آزمون واحد در ۷۰ فایل، lint، format و generated check موفق‌اند. اجرای نهاییِ هر ۳۹ آزمون انتخاب‌شدهٔ مرورگر بدون skip/retry موفق است؛ ورود، مجوزها، CSRF، XSS، خروج، فرم‌های متصل، تنظیمات، پاسخ‌گویی و فوکوس راهنما را پوشش می‌دهد. آزمون تازه ابتدا مشکل برگشت فوکوس را یافت و پس از اصلاح، کل مجموعهٔ انتخاب‌شده دوباره موفق شد. اجرای محلی اصلی روی `http://127.0.0.1:3145/enter` پاسخ ۲۰۰ و بدون خطای JS و سرریز افقی دارد. مجموعهٔ کامل ۲۵۱ سناریویی در این مرحله دوباره اجرا نشده است.

رسید و فهرست حذف‌ها: `docs/quality/PROJECT_CLEANUP_20261106.json`. اندازه‌گیری‌ها در `PERFORMANCE_cleanup-before.json` و `PERFORMANCE_cleanup-after.json` هستند. سرعت پاسخ بک‌اند در این کار تغییر نکرده است.

## نگه‌داری بعدی

پس از توقف سرور توسعه یا build، از پوشهٔ `web` اجرا کنید:

```sh
npm run clean:cache
```

این فرمان فقط کش Next، خروجی موقت آزمون و کش TypeScript را پاک می‌کند؛ build production و نشست‌ها باقی می‌مانند. نخستین build توسعه پس از پاک‌کردن کش ممکن است طولانی‌تر شود. برای استقرار از Docker/standalone موجود استفاده کنید؛ ابزارهای آزمون، PDFها و آرشیوهای طراحی داخل تصویر اجرای محصول کپی نمی‌شوند.
