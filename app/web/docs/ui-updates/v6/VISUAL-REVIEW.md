## استثناهای بررسی‌شده

- جستجو: wrapper و ارتفاع/لبه‌های بیرونی منطبق‌اند؛ عرض input۱۹پیکسل کمتر از مرجع است. SVG جستجوی مرجع عملاً فضای۲۵پیکسلی دارد؛ در محصول عمل submit واقعی با هدف۴۴پیکسلی و نام دسترس‌پذیر حفظ شده است. این تفاوت برای کنترل عملیاتی و دسترس‌پذیری است، نه پنهان‌کردن سرریز.
- متن۲۰۰٪: ارتفاع ثابت۴۴کادر پیام،placeholder را می‌برید. حداقل ارتفاع از line-height و padding همان متن محاسبه شد؛ اختلاف۲۳٫۵۹پیکسلی composer با مرجع رفع شد. پیش‌نویس،صف و API تغییر نکردند.
- سربرگ متن بزرگ: AST-02در۳۲۰وPRO-03/ORG-16به‌دلیل متن زمینه/عنوان متفاوت،wrap و ارتفاع متفاوت دارند. نام/زمینهٔ واقعی حفظ شده و عنوان برای هم‌ارتفاع‌شدن قطع نشده است؛ focus و اقدام در ارتفاع کم قابل دسترس‌اند.
- متن۲۰۰٪: ناوبری مجاز موبایل به دو ردیف۳+۲می‌رود؛ HTML مرجع فقط فونت را بزرگ می‌کند و همان پنج ستون را نگه می‌دارد. ارتفاع و جای مقصدها متفاوت است؛ بازچینی محصول برای جلوگیری از قطع label و طبق خواستهٔ صریح کاربر حفظ شده است. در صفحهٔ عمیق ناوبری پنهان دوباره نمایش داده نمی‌شود.
- فرم/داده: profile bio در DTO نیست؛ تاریخ تولد و validation فعلی حفظ‌اند. عکس و نام fixture با اطلس فرق دارند. هیچ فیلد بی‌اثر،شخص نمونه یا شمار طراحی جای دادهٔ واقعی قرار نگرفت.
- inbox/chat: فیلترهای عملیاتی،دعوت‌های پیام‌رسان و آغاز گفتگو با داده/ACL موجود باقی‌اند؛ prototype آن‌ها را در همهٔ حالت‌ها نشان نمی‌دهد. تعداد ردیف‌ها،presence و متن پیام یکسان نیستند؛ برابری هندسی حباب‌های دارای متن متفاوت ادعا نمی‌شود.
- دستیار: متن pending/context/source و خطاها واقعی‌اند؛ پاسخ/تاریخچهٔ نمونه تزریق نشد. ستون مرجع همان inbox حساب است و با Messenger واقعی۲۸۰/۳۱۲بازاستفاده شده است. کنترل صوت AI قرارداد ندارد؛ دکمهٔ بی‌اثر برای تقلید تصویر افزوده نشد،پس عرض داخلی textarea با قاب نمونه فرق دارد.

## اصلاح‌های بازاندازه‌گیری‌شده

عرض تبلت Scene و header،padding فرم،photo compact و نخستین input پروفایل،رنگ paragraph کارت،wrapper آموزشگاه،عرض حداکثر inbox،ستون chat در۷۶۸،فاصلهٔ ریل تبلت۸،نوار نوشتن دستیار و هدف لمس titlelink در همین چرخه اصلاح شدند. صورت علت/مالک در STYLE-OWNERSHIP است. اختلاف‌های باقی‌ماندهٔ داده،کنترل مجاز یا API در بالا و ماتریس درج شده‌اند؛ «pixel perfect» یا تأیید همه۱۵۱حالت اعلام نمی‌شود.

کیبورد با ارتفاع۵۴۰مدل شده است؛ IME فیزیکی،safe-area واقعی،میکروفن گوشی،permission دفترچه و provider پرداخت با این تصاویر تأیید نمی‌شوند. آزمون صوت از دستگاه مصنوعیِ صریح استفاده کرده است. حالت‌های بدون screenshot مستقل در CSV همان‌طور مشخص‌اند؛ تست رفتار جای شاهد تصویریِ آن حالت نیست.
