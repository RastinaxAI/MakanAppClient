اندازه‌های اصلی۳۹۰×۸۴۴،۸۳۴×۱۱۱۲و۱۴۴۰×۱۰۰۰، به‌علاوه اندازهٔ بومی۳۷۵×۷۲۸ بررسی شدند. آزمون متن۲۰۰٪ در هر دو تم، عرض‌های۳۲۰،۳۶۰،۳۹۰،۴۳۰،۷۶۸،۸۳۴،۱۰۲۴،۱۱۹۴،۱۲۸۰،۱۴۴۰و۱۹۲۰ با ارتفاع۵۴۰و حالت‌های۸۴۴×۳۹۰و۳۹۰×۳۲۰ را پوشش می‌دهد. در inbox متن بزرگِ۳۲۰/۳۹۰/۴۳۰، containment ورودی و جدایی از تب‌ها نیز سنجیده می‌شود. صرف بررسی overflow سند معیار قبولی نبوده است.

در مسیرهای آزموده‌شده، خطای JavaScript یا fallback خطای رندر باز نماند. شکست‌های HTTP عمدی، پیام خطای واقعی و retry را آزمودند. Escape، بازگشت focus، نگه‌داری draft و انتخاب، منع ارسال بدون مجوز، رویداد System، @، جست‌وجوی sequence، edit conflict، pin/delete receipt، حضور خصوصی/منقضی، شکست عضو دوم و retry فقط همان عضو، لمس و پنجره‌ها بررسی شدند. ضبط/پخش/حذف/ارسال و کشیدن برای لغو با سخت‌افزار مصنوعی آزموده شد؛ میکروفن و صفحه‌کلید فیزیکی موبایل و real-time واقعی همچنان آزموده نشده‌اند.

مجموع تمام chunkهای JS تولیدی۲٬۹۸۳٬۹۹۸بایت و CSS۲۹۰٬۷۳۸بایت است؛ gzip محاسبه‌شده به‌ترتیب۸۷۲٬۸۲۰و۵۰٬۷۱۷بایت. این‌ها مجموع خروجی همهٔ مسیرها هستند، نه دانلود یک صفحه یا سنجهٔ سرعت شبکه. وابستگی تازه صفر است. فایل خروجی یا runtime دیگری برای جایگزینی محصول ساخته نشده است. تصاویر، اسکریپت‌های اندازه‌گیری و خروجی تست این نوبت بیرون workspace نگه داشته می‌شوند.

کمبود typing، دارایی‌های اختصاصیِ ارائه‌نشده، دادهٔ متفاوت، native keyboard و عدم اتصال زنده مانع ادعای برابری تمام۲۰۷قاب‌اند. نگاشت هر ردیف وضعیت همین محدودیت‌ها و شواهد خانواده را حفظ می‌کند؛ «pixel perfect» سراسری ادعا نمی‌شود. انتشار عملیاتی انجام نشده است.
