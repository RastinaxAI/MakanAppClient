# پیاده‌سازی مرجع کامل V4 آبی — ۶ نوامبر ۲۰۲۶

مرجع فعال، `MakanApp_Frontend_Complete_UI_UX_FA_v4_Blue.pdf` و HTML/CSS قابل ویرایش همراه همان سند در `design/reference-v4` است. شناسهٔ SHA-256 سند: `20fa00d3abf35889d302ec237f5eded1e8f86e5c0b1e9abe771f5de0fbae001c`.

این تحویل فقط برنامهٔ Next.js داخل `web/` را تغییر می‌دهد. ۴۶۷ شناسهٔ سند طبقه‌بندی شده‌اند: ۴۲۶ نمای کلاینت و ۴۱ نمای مالک، متعلق به برنامهٔ مستقل `MakanManagement`. نمای مالک و endpoint مالک به این کلاینت اضافه نشده‌اند.

## تغییرات در محصول

- رنگ‌های روشن/تاریک، فونت مرجع، کادرها، ردیف‌ها، فرم‌ها، منوهای تأیید و فاصله‌های پایه از منبع V4 مصرف می‌شوند. لوگوی آبی ارسالی کاربر حفظ شده است.
- ناوبری پنج مقصد، ریل تبلت و سایدبار ۲۱۰ پیکسلی دسکتاپ هماهنگ شده‌اند. قاب دستگاه، ساعت ساختگی، توضیح‌های بیرون طرح و پاورقی PDF وارد محصول نشده‌اند.
- عنوان و اقدام اصلی آموزشگاه در یک هدر نمایش داده می‌شود؛ بخش‌های آموزشگاه از منوی هدر در دسترس‌اند. کلاس مدیر در دسکتاپ جدول و جزئیات کنار هم دارد؛ تعدادها از دادهٔ دریافت‌شده محاسبه می‌شوند. کلاس دانش‌آموز و مدرس ردیف‌های قابل استفاده در همهٔ اندازه‌ها دارد.
- فرم پروفایل، منوی عکس، تنظیمات گروه‌بندی‌شده، راهنما، نصب برنامه، وضعیت ارتباط و فهرست واقعی درس/ترم با اجزای مشترک تکمیل شده‌اند. خوانایی بزرگ‌تر و کاهش حرکت، تنظیم‌های محلی‌اند.
- پیام‌رسان و دستیار از تم و آیکون‌های مشترک استفاده می‌کنند. نظرسنجی/آزمونک، چک‌لیست، زمان‌بندی و لغو پیام و پوشه‌های موجود به قرارداد منتشرشده متصل شده‌اند. مجوز مؤثر گفتگو همچنان شرط نمایش ابزار انتشار است.
- ایجاد/بازبینی برنامهٔ هفتگی، ویرایش قاعدهٔ تازه ثبت‌شده با نسخهٔ سرور و پایان جلسه با تأیید کاربر و rowVersion واقعی اضافه شده‌اند.
- اصلاح‌های قبلی ورود، رقم‌بودن شماره/کد، خروج، نقش/فضای کار، ۴۰۴ گفتگوی آموزشگاه، پیش‌نویس‌ها، دعوت و حریم خصوصی حفظ شده‌اند. تصویر نمونهٔ «همه» سیاست ذخیره‌شدهٔ کاربر را خودکار بازنویسی نمی‌کند.

## مرز شواهد

[جدول ردیابی](design/V4_TRACEABILITY_FA.md) و `design/v4-traceability.json` برای هر شناسه، مسیر، فایل و خانوادهٔ API را ثبت می‌کنند. حالت‌های یک جریان ممکن است مسیر مشترک داشته باشند. نگاشت ۴۲۶ نما به معنی آزمایش مستقل همهٔ حالت‌ها، اتصال زندهٔ همهٔ آن‌ها یا برابری پیکسلی کامل نیست.

۴۲۶ نمای کلاینت با کنترل‌های React و ورودی/دکمهٔ واقعی رندر و با تصویر منبع مقایسه شده‌اند. این نماها در محیط مرور طراحی، داده و تعامل محلی دارند؛ تصویر یا iframe جای محصول نیستند و رویداد نمایشی، رسید موفقیت سرور تولید نمی‌کند. واردکردن هر نما جدا و سمت سرور است؛ اطلس همهٔ نماها در بستهٔ اولیهٔ مرورگر بارگیری نمی‌شود. مسیر `/preview/reference` در اجرای معمول production پاسخ ۴۰۴ دارد.

از ۲۰ مسیر عملیاتی، در پنج ترکیب اندازه/تم مجموعاً ۱۰۰ تصویر ثبت شده است: موبایل ۳۹۰×۸۴۴ روشن/تاریک، تبلت ۸۲۰×۱۱۸۰ روشن و دسکتاپ ۱۴۴۰×۱۰۰۰ روشن/تاریک. دادهٔ آزمایشی در تصاویر صریحاً برچسب دارد. نمونه‌ها و پنج contact sheet محصول و مجموعه‌ای از مقایسه‌های مرجع به‌صورت دستی بازبینی شده‌اند؛ کل اختلاف‌ها خودکار محاسبه شده‌اند.

گالری آفلاین در `output/review/mk-v4/index.html`، تصویر منبع، خروجی، هم‌پوشانی و اختلاف را جدا نشان می‌دهد. میانگین خطای رنگ MAE در `reference/comparison.json` یک معیار ۰ تا ۲۵۵ است، نه درصد تکمیل یا امتیاز کیفیت. فاصلهٔ امن دکمه، تمرکز صفحه‌کلید و برچسب نمونه از اختلاف‌های عمدی‌اند.

## اتصال و درخواست‌های مشخص برای بک‌اند

سطح مجاز کلاینت اکنون ۳۰۴ عملیات منتشرشده دارد. ۱۵ عملیات نظرسنجی، چک‌لیست، پیام زمان‌بندی و پوشه اضافه شده‌اند؛ مسیرها از `contracts/openapi.json` و مدل‌های تولیدشده گرفته می‌شوند. پایهٔ سرور در `config/network.json` است؛ `BACKEND_BASE_URL` در صورت تنظیم آن را بازنویسی می‌کند. نشست و توکن همچنان سمت BFF می‌مانند.

| بخش | رفتار فعلی | وابستگی لازم |
|---|---|---|
| نظرسنجی/آزمونک | ایجاد، دریافت، رأی، بستن و رأی‌دهندگان غیرناشناس؛ نسخهٔ رأی/تعریف واقعی | اجرای زندهٔ سناریو با حساب و دادهٔ آزمایشی بک‌اند برای تأیید یکپارچه‌سازی نهایی |
| چک‌لیست | ایجاد/ویرایش تعریف و وضعیت آیتم؛ expectedVersionهای مستقل | مانند بالا |
| پیام زمان‌بندی | زمان واقعی UTC از ورودی شمسی، فهرست صفحه‌بندی و لغو تأییدشده | مانند بالا؛ آزمون fixture زمان ارسال واقعیِ worker سرور را ثابت نمی‌کند |
| پوشه | خواندن، نام/فقط‌نخوانده، محتوای پوشه و حذف؛ رشته‌های نوع و overrides حفظ می‌شوند | `FolderConversationTypes` در OpenAPI فقط string است؛ enum/نحوهٔ رمزگذاری flags و قرارداد ساخت باید صریح منتشر شود. ساخت پوشه/نوع تازه مسدود است؛ مقدار فرضی ارسال نمی‌شود. |
| برنامهٔ هفتگی | POST ایجاد و PATCH نسخه‌دار روی همان رسید دریافتی | برای ورود دوباره/ویرایش قاعدهٔ قبلی، GET قاعده/فهرست قواعد به‌همراه rowVersion منتشر شود. پس از خروج، قاعدهٔ قبلی از حافظه جعل نمی‌شود. |
| MK-377/378/379 | استودیوی دستیار با نمونهٔ تعاملی و برچسب پیش‌نمایش | قرارداد کارهای پایدار تولید خروجی، وضعیت پردازش و دریافت خروجی |
| MK-440/441/442 | مرجع کامل در مرور طراحی؛ صفحهٔ محصول با توضیح عدم دسترسی و بدون mutation | قرارداد معتبر تغییر شماره، حذف حساب و تیکت پشتیبانی؛ اکنون endpoint فرضی وجود ندارد. |

در ثبت تصاویر، تنها خطای سرویسِ انتظاررفته، ۵۰۳ مذاکرهٔ SignalR در fixture فاقد hub بود؛ fallback دوره‌ای فعال بود. این مشاهده، مدرک خرابی hub سرور عمومی نیست. عملیات جدید این مرحله روی دادهٔ سرور عمومی اجرا نشده‌اند؛ شواهد اتصال زندهٔ تاریخی در گزارش‌های قبلی از آزمون‌های ایزولهٔ این تحویل جدا هستند.

## بازتولید و آزمون

نتیجهٔ واقعی و کد خروج بررسی‌ها در `docs/quality/V4_20261106_CHECKS.json` ثبت شده است: ۴۹۶ آزمون واحد در ۶۹ فایل، مجموعهٔ کامل ۲۴۴ سناریوی مرورگر و ۲۲ بازآزمایی پس از اصلاح نهاییِ ظاهر فرم‌ها، همگی موفق‌اند. مجموعهٔ کامل روی build قبل از اصلاح آخرِ فاصله/عرض/سوییچ و زیرمجموعهٔ مرتبط روی build نهایی اجرا شد؛ شناسهٔ هر دو build در رسید موجود است. واحدها، TypeScript، lint، قالب‌بندی و تولید قرارداد نیز روی نسخهٔ نهایی بررسی شدند.

مجموعهٔ جدید، نگه‌داری پیش‌نویس پس از ۵۰۳/reload، تکرار هویت عملیات، تعارض ۴۰۹، وضعیت تأییدشدهٔ چک‌لیست، لغو پیام، حفظ قواعد پوشه، منع انتشار بدون مجوز، نبود mutation پیشنهادها، دسترسی نمای مالک و فاصلهٔ دکمهٔ موبایل را می‌سنجد. آزمون نهایی، هم‌عرضی گزینه‌ها با پرسش و کارکرد سوییچ با صفحه‌کلید را هم کنترل می‌کند. ۱۵ شکست دور اول شامل انتظارهای چیدمان قبلی و رقابت زمانیِ آزمون تعارض منبع اصلاح شدند؛ اجرای کامل موفق بعدی و بازآزمایی نهایی از آن دور ناموفق جدا ثبت شده‌اند.

```bash
npm ci
npm run generated:check
npm run lint
npm run typecheck
npm test
npm run build -- --webpack
PLAYWRIGHT_CHANNEL=chrome npx playwright test
```

مرور مستقل با دادهٔ ساختگی، پس از ساخت:

```bash
node scripts/v4-review-server.mjs
```

نشانی مرور: `http://127.0.0.1:3158/preview/reference`. این launcher از fixture محلی ۳۴۵۸ و نشست موقت جدا استفاده می‌کند. سرور متصل کاربر روی ۳۱۴۵ از `scripts/integration-review.mjs` و پیکربندی اصلی استفاده می‌کند. سرور مقصد این مرحله deploy نشده است.
