# محدودیت‌های قرارداد V6 در کلاینت فعلی

مبنای این ممیزی OpenAPI عمومی همین بک‌اند ۸۰۹۰ در شروع نوبت است: ۴۰۳ مسیر،۴۵۴ عملیات،۷۳۲ schema. مسیرها و عملیات با snapshot بسته هم‌خوان‌اند؛ تفاوت سه alias تکراری است. قرارداد تولیدی کلاینت ۳۲۹ عملیات و۵۷۱ schema دارد و endpoint مدیریت پلتفرم ندارد. بستهٔ طراحی، endpoint پیشنهادی را موجود نمی‌کند. احراز هویت، BFF، قفل نشست و بررسی revision حفظ شده‌اند.

| وابستگی | موقعیت‌های متأثر | نتیجهٔ فعلی و ورودی لازم |
|---|---|---|
| دفترچهٔ شمارهٔ غیرعضو و sync | CON-03…07،12…14 | قرارداد فعال contacts به userId ثبت‌شده نیاز دارد. فرم دستی، کشور/شماره را کاننیکال می‌کند و resolve معتبر را ذخیره می‌کند. شمارهٔ پیدا‌نشده با userId ساختگی ذخیره نمی‌شود. consent، native permission، bulk result، delta/cursor، tombstone و رفع تعارض چنددستگاهی به backend و کلاینت native نیاز دارند. هیچ دفترچه‌ای خودکار بارگذاری نمی‌شود. |
| پروفایل و onboarding | AUT-04،PRO-02 | CompleteProfileCommand فقط نام،نام خانوادگی،نام نمایشی،username و تاریخ تولد دارد؛ bio و وضعیت تأیید consent/onboarding ندارد. فیلد بی‌اثر یا موفقیت ثبت جعلی اضافه نشد؛ اعتبارسنجی سن و تاریخ فعلی حفظ شد. |
| عملیات حساب | PRO-10…12 | تغییر شماره، حذف حساب و تیکت پشتیبانی قرارداد تأییدشده ندارند. صفحهٔ راهنمای موجود، محدودیت واقعی را نشان می‌دهد. نصب PWA مسیر فعلی خود را دارد. |
| جستجو و رسید پیام | MSG-02،05،13 | جستجوی عمومی فایل در حساب و صف درخواست پیام API مصوب ندارند؛ DEC-019 باز است. رسانهٔ همان گفتگو و read cursor تجمیعی فعال‌اند؛ فهرست خوانندگان/تحویل تفصیلی یک پیام ساخته نشده است. |
| زمینهٔ رسمی آموزشگاهی | MSG-15…19،26…30 | سرور هنوز زمینهٔ جاری آموزشگاه را برای منبع سازمانی مصرف می‌کند. صندوق حساب ثابت می‌ماند؛ ورود به منبع سازمانیِ دیگر همچنان انتخاب صریح زمینه می‌خواهد. header جدید یا تغییر پنهانی نقش ساخته نشد. برای اجرای کامل per-request source ACL به adapter سرور نیاز است. PersonalClass با Organization/Class اشتباه نمی‌شود و عضویت سازمانی مجوز مستقل ایجاد نمی‌کند. |
| نقش محلی کلاس | EXC-01…03،20 | PersonalClassDto خلاصهٔ نقشِ خودِ عضو را ندارد. roster مجاز صفحه‌بندی دارد و درخواست آن همگانی نیست؛ خواندن اولین۱۰۰نفر اثبات نقش همهٔ اعضا نیست. برچسب نمونهٔ مدرس و شرح اطلس وارد دادهٔ واقعی نشده است. self membership/role summary مجاز لازم است. |
| چرخهٔ رسمی/عضویت | EXC-08…15،MSG-18…31 | کلاینت metadata، binding، capability، Ready و repair202 واقعی را کنترل می‌کند. یکتایی Group/Channel، ظرفیت آخر و دعوت+join هم‌زمان به آزمون تراکنش و worker واقعی سرور نیاز دارند؛ fixture آن‌ها را اثبات نمی‌کند. |
| زمینهٔ هر درخواست AI | AST-03،05 | payer و منابع مجاز انتخاب می‌شوند؛ nonce/body و زمینهٔ درخواست نامعلوم نگه داشته می‌شود. تغییر نقش، payer یا زمینه را پنهانی عوض نمی‌کند. انتخاب آزاد همهٔ زمینه‌ها در هر درخواست بدون پشتیبانی سرور اضافه نشد. سرویس واقعی AI، اشتراک و ingest در این نوبت آزموده نشده‌اند. |
| خانواده و خرید فروشگاهی | FIN-03،08 | CreateOrderCommand فیلد beneficiary/family ندارد. خرید فعلی برای مالک واقعی است. بازیابی رسید فروشگاهی قرارداد تأییدشده ندارد و دکمهٔ موفقیت ساختگی ارائه نمی‌شود. آزمون provider/sandbox مستقل هنوز لازم است. |
| درخواست و راه‌اندازی سازمان جدید | FIN-09…15،ORG-20 | API فعال این کلاینت workflow جدید مدرس حقیقی/حقوقی،مدارک و provisioning را کامل نمی‌کند. خرید/ظرفیت سازمان موجود برای Manager حفظ شده است. افزودن این محصول نیازمند قرارداد و مجوز مصوب است. |
| عرضهٔ مستقل آموزشی | EXC-16…18 | تمام extra.* آموزشیِ پیشنهادی خاموش مانده‌اند. تکلیف/آزمون مجاز آموزشگاه فعال می‌مانند. |
| اپ‌های جدا | ADM-01…14،LND-01…04 | پنل مالک و لندینگ در این کلاینت جایگزین نشده‌اند؛ AGENTS صریحاً تغییر اپ مالک را منع می‌کند. تغییرهای sibling حفظ شده‌اند. |

ضبط صوت مرورگر به همان FileAsset/BFF و صف پیام موجود متصل شده است؛ مجوز فقط با شروع ضبط، توقف و حذف پیش‌نویس و ارسال جدا هستند. آزمون با دستگاه صوتی مصنوعیِ اعلام‌شده، انتقال/ACL کلاینت را بررسی می‌کند؛ میکروفن فیزیکی، مرورگر گوشی و مجوز native باید روی دستگاه واقعی بررسی شوند.

برای عبور گیت‌های سروری، مخزن/محیط تست backend و قرارداد مصوبِ ردیف مربوط لازم است. هیچ‌یک از حالت‌های وابسته، صرف نمایش UI یا پاسخ fixture موفق اعلام نمی‌شوند.
